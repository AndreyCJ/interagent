## Что где правда (правило для агентов)

1. **Рантайм-события** (backend → frontend) — описаны в `04-events.md`.
2. **Принципы, слои, зависимости** — только в `05-architecture.md`.
3. **Bind-методы и их контракт** — только в `06-bind-contracts.md` (типы данных — в коде).
4. **Решения об интеграциях / инференсе / хранилище** — только в ADR. Если в 01-tz упомянуто — там ссылка (ADR-XXX).
5. **STT — только локально (whisper.cpp).** LLM — локальный (llama.go) или облачный OpenAI-совместимый по выбору пользователя (см. ADR-001, ADR-004, ADR-005). apiKey хранится зашифрованным.
6. **Изменить архитектуру** — только через ADR (`docs/adr/README.md`).
