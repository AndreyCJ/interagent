# NFR: Нефункциональные требования

**Дата:** 2026-07-30
**Статус:** Утверждён

---

Все требования измеряются на целевой конфигурации: MacBook Air M1, 8 ГБ RAM, macOS 14+. Инференс — локальный (STT: whisper.cpp; LLM: llama.go) либо облачный (OpenAI-compatible) по выбору пользователя (см. ADR-001, ADR-004, ADR-005).

| ID     | Название              | Категория     | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                  | Приоритет | Проверка                                                                                                                                                                                              |
| ------ | --------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NFR-01 | Задержка ответа       | Performance   | Время от конца фразы интервьювера до появления подсказки — не более 5 сек, целевое 2 сек. Измеряется для локального и облачного LLM (оба режима ADR-001/ADR-004).                                                                                                                                                                                                                                                                         | High      | Замер 10 итераций: стоп-время после подачи тестового аудио до отрисовки оверлея                                                                                                                       |
| NFR-02 | Конфиденциальность    | Security      | Аудио и скриншоты не покидают устройство **по умолчанию**. STT — локальный (whisper.cpp), аудио в сеть не уходит никогда. В облачный LLM уходит текст транскрипции/OCR, а также **скриншот как изображение** — но только если (а) включён облачный провайдер и (б) выбран путь «отправить скриншот как есть» (multimodal, ADR-005), всегда с индикатором и согласием (ADR-004). Аудио (микрофон/системный звук) в сеть не уходит никогда. | Critical  | Аудит сетевых вызовов через прокси (mitmproxy / Charles): аудио отсутствует всегда; изображение скриншота уходит **только** при включённом облачном провайдере + direct-image режиме и с индикатором. |
| NFR-03 | Нагрузка на CPU       | Performance   | Приложение в режиме ожидания (оверлей открыт, ничего не обрабатывается) — не более 5% CPU (одно ядро). При локальном инференсе — не более 80% на 10 сек. При облачной обработке — не более 10%.                                                                                                                                                                                                                                           | Medium    | `pidstat` / `top` в состояниях: idle, локальная обработка, облачная обработка                                                                                                                         |
| NFR-04 | Click-through оверлей | UX            | Окно оверлея **по умолчанию** не перехватывает события мыши и клавиатуры (сквозной клик на всей площади). Кликабельный (интерактивный) режим переключается глобальным шорткатом (ADR-006) и в нём окно может принимать ввод (ручной ввод, настройки).                                                                                                                                                                                     | High      | Тест: клик по произвольной точке оверлея в click-through режиме — событие уходит в окно под ним (Xcode Accessibility Inspector / CGEvent); переключение шорткатом меняет режим                        |
| NFR-05 | Глобальные шорткаты   | UX            | Все шорткаты приложения работают, когда окно не в фокусе, в том числе если другое приложение активно (в fullscreen).                                                                                                                                                                                                                                                                                                                      | High      | Тест: 10 шорткатов подряд из другого приложения — все сработали                                                                                                                                       |
| NFR-06 | Graceful degradation  | Reliability   | Падение или таймаут STT/LLM/OCR не роняет приложение. Пользователь видит сообщение в оверлее: «Ошибка распознавания / ответа» с предложением повторить.                                                                                                                                                                                                                                                                                   | Critical  | Инъекция ошибок в каждый адаптер (network timeout, invalid auth, corrupted response) — приложение не падает                                                                                           |
| NFR-07 | Потребление RAM       | Performance   | Приложение в режиме ожидания — не более 200 МБ RAM. При обработке — не более 400 МБ (облако) / локальный LLM — до 4 ГБ с предупреждением пользователю.                                                                                                                                                                                                                                                                                    | Medium    | `vmmap` / Activity Monitor в состояниях: idle, облачная обработка, локальная обработка                                                                                                                |
| NFR-08 | Размер бинарника      | Compatibility | Размер установленного приложения без локальных моделей — не более 50 МБ. Модели скачиваются отдельно.                                                                                                                                                                                                                                                                                                                                     | Low       | `du -sh` на скомпилированном .app                                                                                                                                                                     |
| NFR-09 | Логирование ошибок    | Reliability   | Все ошибки записываются в локальный лог с timestamp, stage, контекстом. Пользователь может экспортировать лог одной кнопкой. Без телеметрии (opt-in).                                                                                                                                                                                                                                                                                     | Medium    | Проверка наличия лог-файла после каждого сценария ошибки                                                                                                                                              |
| NFR-10 | Автообновление        | UX            | Обновления проверяются при старте. Уведомление о новой версии — не навязчивое (badge / тост). Фоновая загрузка с подтверждением установки.                                                                                                                                                                                                                                                                                                | Low       | Mock-обновление: сервер возвращает новую версию — UI показывает уведомление                                                                                                                           |
| NFR-11 | Шифрование ключей     | Security      | API-ключи облачных LLM-провайдеров хранятся в SQLite только в зашифрованном виде (AES-256-GCM). Мастер-ключ шифрования — в macOS Keychain (сервис `com.interagent.keys`).                                                                                                                                                                                                                                                                 | Critical  | Проверить: в БД нет plaintext apiKey; при удалении Keychain-ключа расшифровать нельзя; экспорт лога не содержит ключи.                                                                                |
