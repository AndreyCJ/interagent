# ТЗ: Программа для отображения подсказок

---

## 1. Зачем

Современные собеседования могут требовать совершенно разные знания, в большей мере это какие то энциклопедические вопросы, которые можно загуглить/посмотреть в документации за 1 минуту.
Но они не проверяют как человек мыслит.

Мне очень понравилось как сказал Тимур Шемсудинов:

```
Человека в наше время нужно оценивать по общей сообразительности, ответственности и честности, а знания - вторично
```

По моему личному опыту могу сказать, что забываются самые, казалось бы, самые простые вещи, которые ты может исользовал или даже делал, но просто забыл.
И плохой интервьювер из-за этого обязательно забракует вас.

Суть приложения - прозрачное окно с подсказками и ответами на вопросы, которые задает собеседующий, либо решение задач по скриншоту экрана.
Функционал может расширяться, это только самые основные функции.

## 2. Основные сущности

| Сущность    | Что хранит                                                                          |
| ----------- | ----------------------------------------------------------------------------------- |
| Session     | id, chatHistory (Message[]), startedAt                                              |
| Message     | role ('interviewer' \| 'user' \| 'assistant'), text, timestamp                      |
| AgentConfig | id, name, model, systemPrompt, temperature                                          |
| AppSettings | theme ('dark' \| 'light' \| 'transparent'), language, shortcuts, autoStartListening |
| Shortcut    | id ('mic_toggle'), label, keys (string[]), enabled                                  |
| AudioDevice | id, name, isDefault                                                                 |

## 3. Сценарии.

### Сценарий 1. Автоответ по транскрипции интервьювера

1. Программа обрабатывает звук через whisper (или подобную ллм для перевода голоса в текст) и отправляет его в ллм.
2. Ответ выводится в окне.

### Сценарий 2. Ответ по скриншоту

1. По шорткату или по нажатию на конпку скриншота (можно выбрать область либо весь экран), программа сканирует текст.
2. Ответ выводится в окне.

## 4. Словарь

Минимальный словарь (расширяемый):

### 4.1 Термины

| Термин           | Описание                                                            |
| ---------------- | ------------------------------------------------------------------- |
| STT              | Speech-to-Text — преобразование голоса в текст (Whisper и аналоги)  |
| LLM              | Large Language Model — генерация ответа на переданный контекст      |
| Overlay / HUD    | Прозрачное окно поверх всех окон для отображения подсказок          |
| OCR              | Optical Character Recognition — распознавание текста со скриншота   |
| Screenshot layer | Выделение области экрана для захвата (регион или весь экран)        |
| Агент            | Конфигурация LLM (модель, apiKey, prompt) для разных сценариев      |
| Сессия           | Локальный чат с историей вопросов и ответов текущего интервью       |
| Шорткат          | Глобальная комбинация клавиш для триггера действий (скриншот, mute) |

### 4.2 События приложения

| Событие              | Когда                                      | Поля                             |
| -------------------- | ------------------------------------------ | -------------------------------- |
| `session_started`    | начата новая сессия интервью               | session_id, timestamp            |
| `audio_captured`     | захвачен фрагмент аудио с микрофона        | session_id, duration_ms          |
| `transcription_done` | STT вернул текст                           | session_id, text, confidence     |
| `screenshot_taken`   | сделан скриншот (регион / весь экран)      | session_id, region               |
| `ocr_done`           | OCR распознал текст со скриншота           | session_id, text                 |
| `llm_requested`      | отправлен запрос к LLM                     | session_id, model, tokens_in     |
| `answer_received`    | получен ответ от LLM                       | session_id, model, tokens_out    |
| `answer_displayed`   | ответ показан в оверлее                    | session_id                       |
| `error_occurred`     | ошибка на любом этапе                      | session_id, stage, error_message |
| `settings_changed`   | изменены настройки пользователя или агента | user_id, changed_keys            |
| `agent_switched`     | пользователь переключил агента             | session_id, from_agent, to_agent |

## 5. Роли пользователей

| Роль     | Описание                                                               | Действия                                                  |
| -------- | ---------------------------------------------------------------------- | --------------------------------------------------------- |
| Кандидат | Пользователь, проходящий интервью. Основная целевая аудитория.         | Управление сессией, настройка агентов, просмотр подсказок |
| Оператор | Пользователь, калибрующий систему перед использованием (необязательно) | Настройка шорткатов, выбор модели, тестирование           |

Система однопользовательская — роли не пересекаются в рантайме. Оператор — тот же кандидат в режиме настройки.

## 6. Интеграции

| Система         | Назначение                     | Варианты                                    | Примечание                                      |
| --------------- | ------------------------------ | ------------------------------------------- | ----------------------------------------------- |
| STT (Whisper)   | Перевод голоса в текст         | whisper.cpp (локально)                      | ADR-001: выбран локальный инференс              |
| LLM             | Генерация ответа               | llama.cpp / llama.go (локально)             | ADR-001: выбран локальный инференс. Модели 3–8B |
| OCR             | Распознавание текста на скрине | Tesseract / Apple Vision / LLM (multimodal) | Зависит от точности и платформы                 |
| Скриншот экрана | Захват изображения             | Нативное API ОС (CGDisplay, Win32)          | macOS: `CGDisplayStream`, Windows: DXGI         |

Все интеграции — внешние, подключаются через адаптеры. Ядро не должно зависеть от конкретного провайдера.

## 7. Ограничения и допущения

Нефункциональные требования — см. [01-nfr.md](01-nfr.md).

- **Платформа.** Первая версия — macOS (ARM/Intel). Windows — следующий этап.
- **Фреймворк.** Wails v2 — единственный бэкенд. Замена фреймворка не планируется.
- **Always-on-top.** Окно всегда поверх всех окон, кликабельный слой отсутствует (click-through). Реализуется через настройки окна Wails + платформенные вызовы.
- **Одно окно.** Приложение работает в одном окне. Мультимониторные конфигурации — later.
- **Микрофон.** Предполагается наличие рабочего микрофона. Без него аудио-сценарий недоступен.
- **Интернет.** Для облачных LLM/STT требуется соединение. Локальные модели работают офлайн.
- **Аккаунт.** Серверный бэкенд не предусмотрен. Всё хранится локально (SQLite / файл настроек).

## 8. Этапы разработки

Каждый этап — вертикальный слайс: сначала пишутся тесты (spec / контракты), ты ревьювишь и аппрувишь, только потом реализация. Этап считается готовым, когда тесты зелёные.

### Этап 1: TDD + каркас проекта

- Настройка инструментов: Go (`go test` + testify / gotest), фронтенд (vitest + vue-test-utils), e2e (playwright)
- CI-пайплайн: тесты на каждый коммит (GitHub Actions)
- Пустые тесты для всех будущих модулей (интеграции) — контракты и ожидаемое поведение
- Ты ревьювишь тесты → аппрувишь → идём дальше

### Этап 2: Ядро оверлея + ручной ввод

- Написать тесты на поведение оверлея (открыть/скрыть, click-through, шорткаты) → ревью
- Прозрачное click-through окно (Wails + нативные вызовы)
- Поле ввода текста вручную → отправка в LLM → вывод ответа
- Сохранение истории сессии
- Глобальный шорткат для показа/скрытия окна

### Этап 3: Транскрипция аудио (STT → LLM)

- Написать тесты на контракт STT-адаптера (захват аудио, отправка, ответ) → ревью
- Захват аудио с микрофона (нативное API)
- Интеграция STT (Whisper — локально или API)
- Автоматическая отправка транскрибированного текста в LLM
- Визуальный индикатор "слушаю" / "печатаю"

### Этап 4: Скриншоты (Screenshot → OCR → LLM)

- Написать тесты на захват экрана, OCR-адаптер, multimodal → ревью
- Захват скриншота (регион / весь экран) по шорткату
- OCR распознавание текста
- Отправка распознанного текста в LLM
- Поддержка multimodal LLM (опционально — картинка напрямую)

### Этап 5: Настройки, агенты, полировка

- Написать тесты на UI настроек, сохранение конфига, автообновление → ревью
- UI для управления агентами (модель, промпт, apiKey)
- UI для шорткатов и тем оформления
- Автообновление (через встроенный механизм Wails / Homebrew)
- Телеметрия (опционально, opt-in)
