# ADR-002: OCR — Apple Vision vs Tesseract

**Дата:** 2026-08-01
**Статус:** Принято
**Связанные документы:** 01-tz.md §6, 05-architecture.md §3

---

## Контекст

Приложение должно извлекать текст с скриншота экрана. Первичная целевая платформа — macOS. Требования: высокая точность (обычный UI-текст), минимальная задержка, чтобы уложиться в NFR-01 (целевой 2 сек, максимум 5 сек на весь пайплайн Screenshot → OCR → LLM → Render).

## Варианты

### A. Apple Vision (Vision Framework)

| Компонент | Технология                                                  |
| --------- | ----------------------------------------------------------- |
| OCR       | `VNRecognizeTextRequest` (Apple Vision), нативный macOS API |

**Плюсы:**

- Нативно, быстро (Metal / ускорение железом), часто быстрее Tesseract в 2–5×.
- Хорошее качество на типичном UI-тексте (шрифты, контраст).
- Нет внешних зависимостей, небольшой бинарник.
- Работает офлайн, без скачивания языковых пакетов.

**Минусы:**

- Только macOS 10.15+ (ограничено платформой — ок для v1).
- Языки ограничены тем, что поддерживает Vision (обычно EN + системные).
- Нет кросс-платформенной замены без адаптера.

### B. Tesseract 5

| Компонент | Технология                                           |
| --------- | ---------------------------------------------------- |
| OCR       | `tesseract` через cgo-обёртку (go-tesseract / forks) |

**Плюсы:**

- Кросс-платформенно (Linux, Windows, macOS).
- Широкая поддержка языков (traineddata).
- Не зависит от железа.

**Минусы:**

- Медленнее Apple Vision (особенно без оптимизаций).
- Требует cgo → осложняет кросс-компиляцию (`go build` на CI).
- Нужно доставлять языковые пакеты (`rus.traineddata` и др.) — растёт размер.
- Точность хуже на маленьком/размытом UI-тексте.

## Критерии выбора

| Критерий        | A (Vision)        | B (Tesseract) |
| --------------- | ----------------- | ------------- |
| Точность на UI  | ✅ (лучше)        | ⚠️            |
| Скорость        | ✅ (быстрее)      | ⚠️            |
| Кросс-платформа | ❌ (только macOS) | ✅            |
| cgo / сборка    | ✅ (нативно)      | ❌ (cgo)      |
| Размер          | ✅ (мало)         | ⚠️ (языки)    |
| Офлайн          | ✅                | ✅            |

## Решение

Выбран вариант **A — Apple Vision** для v1 (macOS-only).

### Компромиссы

- Кросс-платформенный OCR-адаптер потребует Tesseract или аналога при порте на Windows/Linux — это отдельный ADR.
- Язык интерфейса пользователя несвязан с языком OCR: Vision распознаёт текст на экране вне зависимости от `AppSettings.language`.
