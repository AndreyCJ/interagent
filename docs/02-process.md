# Процесс разработки

**Дата:** 2026-07-30
**Статус:** Утверждён

---

## Цикл этапа

Каждый этап в [00-tz.md](00-tz.md) проходит один и тот же цикл:

```
  ┌─────────────────────────────────────────────────────┐
  │  1. Написать тесты (spec / контракты)               │
  │     ↓                                               │
  │  2. Автор показывает тесты → ты ревьювишь           │
  │     ↓                                               │
  │  3. Реализация функционала                          │
  │     ↓                                               │
  │  4. Все тесты зелёные                               │
  │     ↓                                               │
  │  5. Приёмка (ты проверяешь)                         │
  └─────────────────────────────────────────────────────┘
```

## Правила

1. **Тесты — before код.** Суть тестов ревьювится разработчиком перед их написанием. Без зелёных тестов реализация не принимается.
2. **Один этап — один вертикальный слайс.** Сценарий работает от UI до бэкенда (или от адаптера до UI).
3. **Ревью — блокирующее.** Без твоего аппрува на тесты следующий шаг не начинается.
4. **CI.** Все тесты прогоняются на каждый коммит в `main` / каждый PR.
5. **Исключения.** Если в ходе реализации вскрылся нюанс, которого не было в тестах — тесты дополняются, ревьювится дифф, потом фикс.

## Инструменты

| Слой          | Инструмент                   |
| ------------- | ---------------------------- |
| Go-бэкенд     | `go test` + testify / gotest |
| UI-компоненты | vitest + vue-test-utils      |
| E2E           | Playwright (опционально)     |
| CI            | GitHub Actions               |
