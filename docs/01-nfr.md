# NFR: Нефункциональные требования

**Дата:** 2026-07-30
**Статус:** Черновик

---

Все требования измеряются на целевой конфигурации: MacBook Air M1, 8 ГБ RAM, macOS 14+.

| ID     | Название              | Категория     | Описание                                                                                                                                                                                         | Приоритет | Проверка                                                                                                           |
| ------ | --------------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------- | ------------------------------------------------------------------------------------------------------------------ |
| NFR-01 | Задержка ответа       | Performance   | Время от конца фразы интервьювера до появления подсказки — не более 5 сек, целевое 2 сек. Измеряется для API-режима (STT + LLM).                                                                 | High      | Замер 10 итераций: стоп-время после подачи тестового аудио до отрисовки оверлея                                    |
| NFR-02 | Конфиденциальность    | Security      | Данные микрофона и скриншотов не покидают устройство. Выбран локальный инференс (ADR-001), поэтому передача данных вовне не предусмотрена архитектурно.                                          | Critical  | Аудит сетевых вызовов через прокси (mitmproxy / Charles) — исходящих запросов с аудио/скриншотами быть не должно   |
| NFR-03 | Нагрузка на CPU       | Performance   | Приложение в режиме ожидания (оверлей открыт, ничего не обрабатывается) — не более 5% CPU (одно ядро). При обработке через API — не более 10%. При локальном инференсе — не более 80% на 10 сек. | Medium    | `pidstat` / `top` в трёх состояниях: idle, API-обработка, локальная обработка                                      |
| NFR-04 | Click-through оверлей | UX            | Окно оверлея не перехватывает события мыши и клавиатуры. Сквозной клик работает на всей площади окна (кроме intentionally кликабельных элементов, если появятся).                                | High      | Тест: клик по произвольной точке оверлея — событие уходит в окно под ним (Xcode Accessibility Inspector / CGEvent) |
| NFR-05 | Глобальные шорткаты   | UX            | Все шорткаты приложения работают, когда окно не в фокусе, в том числе если другое приложение активно (в fullscreen).                                                                             | High      | Тест: 10 шорткатов подряд из другого приложения — все сработали                                                    |
| NFR-06 | Graceful degradation  | Reliability   | Падение или таймаут STT/LLM/OCR не роняет приложение. Пользователь видит сообщение в оверлее: «Ошибка распознавания / ответа» с предложением повторить.                                          | Critical  | Инъекция ошибок в каждый адаптер (network timeout, invalid auth, corrupted response) — приложение не падает        |
| NFR-07 | Потребление RAM       | Performance   | Приложение в режиме ожидания — не более 200 МБ RAM. При обработке (API) — не более 400 МБ. Локальный LLM — до 4 ГБ, но с предупреждением пользователю.                                           | Medium    | `vmmap` / Activity Monitor на трёх сценариях                                                                       |
| NFR-08 | Размер бинарника      | Compatibility | Размер установленного приложения без локальных моделей — не более 50 МБ. С локальным инференсом — модели скачиваются отдельно.                                                                   | Low       | `du -sh` на скомпилированном .app                                                                                  |
| NFR-09 | Логирование ошибок    | Reliability   | Все ошибки записываются в локальный лог с timestamp, stage, контекстом. Пользователь может экспортировать лог одной кнопкой. Без телеметрии (opt-in).                                            | Medium    | Проверка наличия лог-файла после каждого сценария ошибки                                                           |
| NFR-10 | Автообновление        | UX            | Обновления проверяются при старте. Уведомление о новой версии — не навязчивое (badge / тост). Фоновая загрузка с подтверждением установки.                                                       | Low       | Mock-обновление: сервер возвращает новую версию — UI показывает уведомление                                        |
