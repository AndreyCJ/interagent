# Bind contracts (Frontend ↔ Backend)

**Date:** 2026-08-01
**Status:** Approved (draft contract for Stage 1)

---

## Rules

1. **Bind methods — synchronous calls** frontend → backend (Wails bindings). The result is returned as `Promise`/`error`.
2. **Async results and statuses — only via events** (see `04-events.md`). Methods that start async work return `void`/`error` (launch success), and the result arrives as an event.
3. **Errors** are returned from a method as `error` (not an `app:error` event). `app:error` — for errors in background async operations.
4. **Data types** — source of truth: Go `internal/port/types.go` ↔ TS `frontend/src/common/types/api.types.ts`. Bindings are generated by `wails generate` → `frontend/wailsjs/`.
5. **Contract changes** — via PR + review (03-process.md); changes affecting an ADR — via ADR (05-process / adr/README).
